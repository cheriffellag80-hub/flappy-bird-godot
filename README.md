# Jujutsu Kaisen Fighting Game

لعبة قتال نمط Tekken مصنوعة بـ Godot Engine

## الميزات

✅ **نظام قتال متقدم**
- ضربات عادية (Punch)
- ركلات قوية (Kick)
- نظام Combo تلقائي
- أضرار متزايدة مع الـ Combo

✅ **نظام AI ذكي**
- العدو يطاردك تلقائياً
- يهاجم عندما تكون بالقرب
- تنويع الهجمات (punch/kick)

✅ **نظام صحة وحياة**
- شريط صحة لكل شخصية
- تأثيرات بصرية عند الضرب
- نهاية اللعبة عند انتهاء الصحة

✅ **التحكم السهل**
- الأسهم: الحركة
- Space: القفز
- Enter (Z): اللكم
- Ctrl (X): الركلة

## كيفية التشغيل

1. ثبت [Godot 4.0+](https://godotengine.org/download)
2. استنسخ المستودع
3. افتح المجلد في Godot
4. اضغط F5 أو Play
